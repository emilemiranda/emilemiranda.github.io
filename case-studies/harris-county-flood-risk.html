Harris County Flood Risk & Social Vulnerability

A GIS decision-support study that combines flood exposure, social vulnerability, and evacuation difficulty into a transparent weighted Final Priority Index for census-tract-level screening in Harris County, Texas.

Project overview

Flood hazard alone does not describe the full set of challenges a community may face during a flood event. This project combines hazard exposure with demographic, housing, and mobility indicators at census-tract level to examine where several dimensions of risk overlap.

Project question: Where do mapped flood hazards overlap with higher social vulnerability and greater evacuation difficulty, and how can a weighted model communicate those dimensions without hiding the component scores?

The project is designed as a reproducible decision-support study using QGIS and public data, with maps and an ArcGIS StoryMap used to explain the analytical framework.

Data and sources

  • FEMA: flood-hazard polygons.
  • U.S. Census Bureau: ACS 5-Year Estimates.
  • Census geography: census-tract boundaries, with ACS attributes joined using tract GEOID.
  • Additional inputs: Harris County public geospatial resources where applicable, as noted in the project documentation.

The supplied project description does not specify the exact FEMA layer vintage, ACS period, census boundary vintage, or individual source URLs. These are important reproducibility fields and should be recorded in the project’s source table before publishing a versioned result.

Method and workflow

  1. Assemble tract geography. Acquire census-tract boundaries and prepare tract identifiers.
  2. Integrate demographic data. Import ACS demographic, housing, and mobility tables and join the attributes to tracts using GEOID.
  3. Measure flood exposure. Intersect FEMA flood-hazard polygons with each tract and calculate the proportion of tract area affected by mapped hazard.
  4. Build the social-vulnerability score. Combine the documented indicators: poverty, household income, older-adult population, disability, limited English proficiency, and housing tenure.
  5. Build the evacuation-difficulty score. Combine households without vehicles, crowded housing, renter concentration, and public-transit dependence.
  6. Normalize and weight the components. Combine the three component scores into the Final Priority Index using the project’s stated weights.
  7. Communicate the model. Prepare QGIS maps and an ArcGIS StoryMap, reviewing the composite result alongside the component layers.

Key findings and interpretation

  • Flood hazard is only one part of community risk. The project documentation emphasizes that physical exposure alone does not capture social vulnerability or evacuation barriers.
  • Combined indicators can change the screening priority. The project notes report that some tracts with moderate flood exposure become higher priorities when social vulnerability and evacuation challenges are elevated.
  • Component maps remain essential. A tract’s composite value should be interpreted beside flood exposure, social vulnerability, and evacuation difficulty so reviewers can identify what is driving the score.
Final Priority Index:
0.40 × Flood Exposure + 0.35 × Social Vulnerability + 0.25 × Evacuation Difficulty

The project notes do not provide named tract rankings or exact index values. The formula and qualitative interpretation are documented here; specific priority locations should be added only from the saved model output.

Outputs and deliverables

  • Weighted Final Priority Index at census-tract level.
  • Flood-exposure, social-vulnerability, and evacuation-difficulty component outputs.
  • Decision-support maps and cartographic layouts produced with QGIS.
  • ArcGIS StoryMap that communicates the purpose, method, and interpretation.
  • Project documentation describing the repository’s data, QGIS project, styles, models, maps, figures, tables, and StoryMap outputs.

Assumptions and limitations

  • Weight sensitivity: the composite result depends on the selected weights and indicator normalization; compare alternative weight settings before drawing strong conclusions.
  • ACS uncertainty: ACS estimates have sampling uncertainty and reference periods, which should be considered when comparing small areas.
  • Data vintage: the exact source versions are not listed in the provided project summary, so they should be documented for reproduction.
  • Screening, not official designation: the Final Priority Index is a project model, not an official emergency-management ranking unless an agency formally adopts and validates it.
  • Interpret alongside components: any composite score can conceal meaningful differences between its underlying measures.

Next steps

  • Publish the exact normalization formulas, source vintages, and indicator handling alongside the weights.
  • Validate the model against historical Hurricane Harvey impact assessments where suitable data are available.
  • Consider adding high-resolution imagery and digital elevation models to compare mapped hazards with terrain context.
  • Assess whether rainfall intensity, stream gauges, land cover, and impervious surfaces provide useful additional context.
  • Compare the custom index with established vulnerability frameworks and explain where the methods agree or differ.
  • Add verified tract examples with their component scores and final index values to make the model interpretable.
